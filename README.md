# Анкета астролога → Telegram

Полностью свой сайт, без Tilda и без платных тарифов.

## Структура
- `index.html` — сама анкета (открывается сразу, реальные поля ввода)
- `api/send.js` — серверная функция, которая принимает данные и шлёт их в Telegram (токен бота хранится на сервере, не виден в браузере)

## Как получить BOT_TOKEN и CHAT_ID
1. В Telegram напишите @BotFather → `/newbot`, получите токен вида `123456:ABC-DEF...`
2. Напишите этому боту любое сообщение
3. В браузере откройте `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`
4. Найдите там `"chat":{"id": ...}` — это CHAT_ID

## Как выложить сайт бесплатно (через Vercel)

1. Зарегистрируйтесь на https://vercel.com (можно через GitHub-аккаунт)
2. Загрузите эту папку в свой репозиторий на GitHub (или используйте Vercel CLI: `npx vercel` из этой папки — попросит войти и всё сделает сам)
3. При импорте проекта в Vercel зайдите в Settings → Environment Variables и добавьте:
   - `BOT_TOKEN` = ваш токен бота
   - `CHAT_ID` = ваш chat id
4. Нажмите Deploy — через минуту сайт будет доступен по бесплатному адресу вида `your-project.vercel.app`
5. При желании подключите свой домен бесплатно в том же разделе Vercel (Domains)
